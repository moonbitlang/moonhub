# Product

<!-- impeccable:product-schema 1 -->

## Platform

Web. Desktop code collaboration with responsive mobile access.

## Product and Users

Moonhub hosts Git repositories, team membership, invitations, Issues, and
same-repository Merge Requests. Site administrators configure SSH and email;
team owners and administrators manage their teams and repositories.

## Constraints

- Preserve MoonBit server-rendered pages, existing URLs, permissions, and forms.
- Keep the existing React code and diff viewer, and the Lucide icon library.
- Never expose internal errors or invite credentials outside their authorization.
- Do not invent activity, counts, repository metadata, or unsupported controls.

## Approved Direction

The user approved a GitLab-inspired left context navigation / right workspace
layout, a collapsible desktop sidebar, a mobile navigation drawer, and separate
team repository, member, and invitation views. Keep the interface restrained,
task-focused, and consistent rather than adding a marketing-style surface.
